Scalable Single Session Control

Force one active session per user, even with 100k+ sessions.

Managing user sessions in high-traffic Odoo environments (2,000+ active users) can be a performance nightmare. Most modules scan the filesystem, causing massive I/O lag. This module uses High-Performance Database Tracking to close sessions instantly without affecting server speed.

Key Features

Ultra Fast Performance

O(1) complexity. Uses DB indexing to find sessions instead of scanning 100k+ files.

Physical Deletion

Forces immediate logout by unlinking session files directly from disk.

Flexible Group Exceptions

Not all users need the same restrictions. You can now exempt specific groups (like Administrators or Managers) from the single-session rule with a simple checkbox in the Group form.

Granular Control

Toggle "Exclude Single Session" on any Odoo Group to allow multiple simultaneous logins for its members.
